# 终端配色方案使用说明

## 功能概述

终端配色方案功能允许用户自定义终端的外观，包括配色主题和字体大小，提供更个性化的使用体验。

## 功能特性

### 1. 多种配色方案

**深色主题（7种）：**
- **Apple Dark** - 现代 macOS 风格（默认）
- **Dracula** - 流行的紫色系主题
- **One Dark** - VS Code 默认深色主题
- **Monokai** - 经典开发者主题
- **Nord** - 冷色调北欧风
- **Solarized Dark** - 护眼配色
- **Gruvbox Dark** - 复古暖色调

**亮色主题（3种）：**
- **Apple Light** - macOS 亮色风格
- **Solarized Light** - 护眼亮色
- **GitHub Light** - GitHub 风格

### 2. 字体大小调节

- 支持 10px - 30px 范围调节
- 提供滑块和按钮两种调节方式
- 实时预览效果

### 3. 持久化存储

- 配色方案和字体大小自动保存到本地
- 下次打开自动恢复上次设置

## 使用方法

### 打开配色选择器

1. 连接到 SSH 服务器后
2. 在终端底部状态栏找到 **画笔图标** 按钮
3. 点击打开配色选择器面板

### 更改配色方案

1. 在选择器面板中浏览深色/亮色主题
2. 点击任意配色方案卡片即可立即应用
3. 终端会实时更新配色效果

### 调整字体大小

**方法一：使用按钮**
- 点击 `-` 按钮减小字体
- 点击 `+` 按钮增大字体

**方法二：使用滑块**
- 拖动滑块到目标大小
- 实时预览字体变化

### 重置为默认

点击面板底部的 **"重置默认"** 按钮，恢复到：
- 配色方案：Apple Dark
- 字体大小：14px

## 技术实现

### 文件结构

```
frontend/src/
├── config/
│   └── terminalThemes.js          # 配色方案定义
├── stores/
│   └── terminalTheme.js           # 配色状态管理
└── components/
    ├── XtermTerminal.vue          # 终端组件（已集成）
    ├── TerminalThemeSelector.vue  # 配色选择器
    └── TerminalStatusBar.vue      # 状态栏（已集成）
```

### 核心特性

- **响应式更新**：配色和字体大小变化实时生效
- **组件化设计**：模块化架构，易于维护
- **性能优化**：使用 xterm.js 原生 API，无需重建终端实例
- **用户友好**：直观的 UI 设计，操作简单

## 扩展配色方案

如需添加新的配色方案，编辑 `frontend/src/config/terminalThemes.js`：

```javascript
{
  id: 'my-theme',           // 唯一标识
  name: '我的主题',          // 显示名称
  category: 'dark',         // 'dark' 或 'light'
  theme: {
    background: '#000000',  // 背景色
    foreground: '#ffffff',  // 前景色
    cursor: '#ffffff',      // 光标颜色
    // ... 16 种 ANSI 颜色
  }
}
```

## 注意事项

1. 配色方案仅影响终端显示，不影响 SSH 连接
2. 字体大小调整会触发终端重新布局
3. 配置保存在浏览器 localStorage 中
4. 不同浏览器/设备的配置独立存储

## 快捷键

目前暂不支持快捷键切换配色，所有操作通过 UI 完成。

## 常见问题

**Q: 配色更改后没有生效？**
A: 请确保终端已连接，刷新页面后重新连接。

**Q: 如何导出我的配色设置？**
A: 当前版本暂不支持导出，配置存储在浏览器本地。

**Q: 能否自定义配色方案？**
A: 需要修改源代码添加，未来版本可能支持 UI 自定义。
