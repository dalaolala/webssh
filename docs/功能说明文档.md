# WebSSH 终端工具 - 系统详细功能说明文档

## 1. 产品概述

WebSSH 是一款基于 Electron + Vue 3 构建的跨平台桌面端 SSH/SFTP 终端管理工具，面向运维工程师、开发者和系统管理员，提供极简风格的一站式服务器连接、命令执行与文件传输体验。

## 3. 详细功能清单

### 3.1 连接管理模块

| 功能名称 | 功能描述 | 前置条件 | 核心规则/边界条件 |
|---------|---------|---------|-----------------|
| 快速连接 | 输入主机、端口、用户名、密码/私钥快速建立 SSH 连接 | 无 | 端口默认 22；支持密码认证和私钥认证两种方式 |
| 历史记录管理 | 保存连接配置，支持快速重连 | 无 | 存储于 LocalStorage，支持按分组筛选、搜索 |
| 分组管理 | 对服务器连接进行分组归类 | 存在历史记录 | 支持新建/重命名/删除分组；未分组记录归入"默认"组 |
| 配置导入 | 从 JSON 文件导入服务器配置 | JSON 格式文件 | 校验 host、username 字段；重复记录自动跳过 |
| 配置导出 | 将本地记录导出为 JSON 文件 | 存在历史记录 | 支持明文导出和加密导出（AES 加密） |
| WebDAV 同步 | 将配置加密同步至 WebDAV 云存储 | 配置 WebDAV 地址 | 加密密钥至少 6 位；下载时按 host+port+username 去重合并 |

**异常场景处理：**

| 异常场景 | 处理方式 |
|---------|---------|
| 连接超时 | 显示超时提示，提供重试按钮 |
| 认证失败 | 区分密码错误/私钥错误，提示用户检查凭据 |
| 网络断开 | 自动检测连接状态，显示断开提示，支持重连 |
| WebDAV 连接失败 | 提供测试连接功能，显示具体错误信息 |

| 功能名称 | 功能描述 | 前置条件 | 核心规则/边界条件 |

| 终端主题配置 | 切换终端配色方案 | 无 | 内置 10+ 配色方案（深色/浅色分类）；字体大小 10-30px |

**异常场景处理：**

## 4. 核心业务流程描述

### 4.1 新建 SSH 连接流程

```
1. 用户填写连接表单（主机、端口、用户名、认证方式）
2. 前端获取 RSA 公钥，使用 RSA+AES 加密敏感凭据
3. 通过 Socket.IO 发送连接请求到后端
4. 后端解密凭据，使用 ssh2 库建立 SSH 连接
5. 连接成功后创建 PTY 会话，返回会话 ID
6. 前端初始化 xterm.js 终端，开始监听数据流
7. 双向数据流建立：用户输入 → Socket → SSH Shell → Socket → 终端渲染
```

### 4.2 SFTP 多文件上传流程

```
1. 用户选择/拖拽多个文件
2. 前端构建上传任务队列，每个任务生成唯一 uploadId
3. 通过 Socket.IO 发送上传请求（包含本地路径、远程路径、uploadId）
4. 后端使用 fs.createReadStream 流式读取本地文件
5. 通过 ssh2 SFTP fastPut 或 createWriteStream 写入远程
6. 每传输 64KB 回报一次进度
7. 前端实时更新进度条，显示百分比和已传输大小
8. 支持中途取消：前端发送 cancel 事件，后端关闭文件流
9. 全部完成后自动刷新目录列表
```

### 4.3 WebDAV 配置同步流程

```
1. 用户配置 WebDAV 地址、用户名、密码、加密密钥
2. 上传：将本地记录序列化为 JSON → AES 加密 → POST 到 WebDAV
3. 下载：GET WebDAV 文件 → AES 解密 → 合并到本地（按 host+port+username 去重）
4. 记录最后同步时间，持久化到 LocalStorage
```

## 5. 非功能性需求

### 5.1 性能要求

| 指标 | 要求 | 实现方式 |
|-----|-----|---------|
| 大文件传输内存 | 内存占用不超过 100MB | Stream 流式传输，分块大小 64KB |
| 终端渲染性能 | 支持高频率输出不卡顿 | xterm.js + Canvas 渲染 |
| 多文件并行上传 | 支持同时上传 5+ 文件 | 任务队列 + 并行处理 |
| 启动速度 | 冷启动 < 3s | Electron 优化、代码分割 |

### 5.2 安全性要求

| 安全项 | 实现方式 |
|-------|---------|
| 凭据传输加密 | RSA 2048 位 + AES 256 位混合加密 |
| 凭据本地存储 | 密码字段不持久化；敏感配置支持加密导出 |
| WebDAV 同步加密 | AES 加密，密钥至少 6 位 |
| 会话隔离 | 每个连接独立 sessionId，防止串话 |

### 5.3 UI 交互规范

| 规范项 | 约定 |
|-------|-----|
| 设计风格 | 极简风格，参考 macOS Human Interface Guidelines |
| 配色 | 深色模式以 #1e1e1e 为主背景；浅色模式以 #f5f7fa 为主背景 |
| 动效 | 过渡时间 0.15s-0.3s；使用 ease 缓动函数 |
| 字体 | 终端使用等宽字体（Consolas/Monaco/JetBrains Mono） |
| 交互反馈 | 所有操作提供即时反馈（Toast 提示/Loading 状态） |

### 5.4 兼容性要求

| 平台 | 支持情况 |
|-----|---------|
| Windows | ✅ 完全支持 |
| macOS | ✅ 完全支持 |
| Linux | ✅ 完全支持 |
| Node.js 版本 | Electron 内置，无需用户安装 |

## 7. 技术架构概览

### 7.1 技术栈

| 层级 | 技术选型 |
|-----|---------|
| 前端框架 | Vue 3 + Vite |
| 状态管理 | Pinia |
| UI 组件库 | Element Plus |
| 终端模拟 | xterm.js + xterm-addon-fit |
| 实时通信 | Socket.IO Client |
| 代码编辑器 | Monaco Editor |
| 后端框架 | Express + Socket.IO |
| SSH/SFTP 协议 | ssh2 |
| 加密算法 | node-forge (RSA) + CryptoJS (AES) |
| 桌面端框架 | Electron 28 |

### 7.2 数据流向

```
用户输入 → Vue 组件 → Pinia Store → Socket.IO → 后端 socketHandler → ssh2 → SSH 服务器
                                    ↓
                              HTTP API → SFTP 路由 → sftpHandler → ssh2 SFTP → 远程文件系统
```
